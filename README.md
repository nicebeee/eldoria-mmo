# Хроники Эльдории

Браузерная 3D MMO-RPG на Three.js: регистрация, 3 класса (воин, маг, лучник), открытый мир, монстры, задания, экипировка, характеристики.

**Играть:** https://nicebeee.github.io/eldoria-mmo/

## Запуск локально

```
npm install
npm run dev
```

или двойной клик по `start.bat` (Windows).

## Управление

WASD — бег, мышь (зажать) — камера, колесо — зум, Пробел — прыжок, ЛКМ по врагу / Tab — цель,
1–3 — умения, 4–5 — зелья, E — говорить/собирать, I — сумка, C — персонаж, L — задания, Esc — закрыть.
